# Data Visualisation: Empowering Business with Effective Insights

## Overview

A data visualisation job simulation completed through Forage, focused on using data visualisation and business analysis techniques to communicate meaningful insights.

## Project Flow

The project followed a structured business-analysis and data-visualisation workflow:

1. **Frame the Business Scenario**
   - Understand the business context and define the analytical focus.

2. **Choose the Right Visuals**
   - Select appropriate visualisations for communicating the required insights.

3. **Create Effective Visuals**
   - Develop the required Power BI visualisations and dashboard.

4. **Communicate Insights and Analysis**
   - Present the analytical findings clearly for a business audience.

## Tools & Skills

- Power BI
- Data Visualization
- Business Analysis
- Data Interpretation
- Data Storytelling
- Dashboard Development

The dashboard was developed to present business insights through interactive visualisations and an easy-to-understand reporting structure.
