# Data Visualisation: Empowering Business with Effective Insights

## 📌 Overview

A data visualisation job simulation completed through Forage, focused on using data visualisation and business analysis techniques to communicate meaningful insights.

The simulation covered:

- Framing the Business Scenario
- Choosing the Right Visuals
- Creating Effective Visuals
- Communicating Insights and Analysis

## 🛠️ Tools & Skills

- Power BI
- Data Visualization
- Business Analysis
- Data Interpretation
- Data Storytelling
- Dashboard Development
